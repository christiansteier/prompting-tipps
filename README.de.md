# Prompting-Tipps fürs Studium

[English](README.md) · **Online:** https://christiansteier.github.io/prompting-tipps/

Eine kleine statische Webseite für Studierende:

- **Prompt bauen** aus fünf Bausteinen: Kontext, Rolle, Aufgabe, Format, Prüfauftrag.
- **Vorlagen** fürs wissenschaftliche Arbeiten und die Prüfungsvorbereitung: Platzhalter ausfüllen und das Ergebnis in einen KI-Chat kopieren.
- **Gut zu wissen:** vier Strategien, fünf Tipps, Regeln für Studienleistungen (eigene Leistung, Kennzeichnen, Datenschutz).

Deutsch und Englisch, läuft offline als Einzeldatei, mit Dunkelmodus und Tastaturbedienung. Gespeichert wird im Browser nur die Sprachwahl, die Eingaben nicht.

## Lokal ansehen

```bash
python3 -m http.server 8000
# http://localhost:8000 öffnen
```
